# 행안부 595건 채점 규칙

지오코더 정확도를 재는 데 쓰는 「행정안전부 제공_7월 호우피해지역 현황」 595건
채점 자산의 **기대값 표기 결함**을 어떻게 다루는지 정의한다.

- 정규화 구현: `scripts/addr_norm.py`
- 채점 하네스: `scripts/15-score-595.py`
- 정정표: `scripts/595-corrections.csv`
- 테스트: `scripts/test_addr_norm.py`

---

## 1. 왜 필요한가

채점 자산의 기대 지번 595건 중 **58건**이 지번 표기 문법에 어긋난 문자열을 담고 있다.
`성동리263-8`(공백 누락), `617-0`(존재하지 않는 부번 0), `산 282-1`(산 접두 뒤 공백).
지오코더가 옳은 필지를 반환해도 이 표기 차이 때문에 오답으로 집계됐다.

즉 이것은 **지오코더의 정확도가 아니라 채점자의 문자열 비교가 만든 오차**다.
규칙은 정확도를 올리는 장치가 아니라, 측정 도구의 계통 오차를 제거하는 장치다.

## 2. 대칭 적용 원칙

정규화는 **기대값과 우리 출력 양쪽에 똑같이** 적용한다. 한쪽만 정규화하면
새 편향이 생긴다. 예외는 정정표뿐이며(§5), 그 예외는 명시적으로 표시하고 감사한다.

## 3. 규칙

| 규칙 | 대상 | 정규식 | 예 |
|---|---|---|---|
| A | 법정동 접미사 뒤 번지 공백 누락 | `(리\|동\|읍\|면\|가)(\d)` → `\1 \2` | `성동리263-8` → `성동리 263-8` |
| B | 말미 `-0` 접미 | `-0(?=\s\|$)` → `` | `617-0` → `617` |
| C-1 | `산` 접두와 번지 사이 공백 | `(?<![가-힣])산\s+(?=\d)` → `산` | `산 282-1` → `산282-1` |

경계 조건 — 각각이 무엇을 **일부러 건드리지 않는지**가 규칙의 본체다.

- **A 는 `로`·`길`을 제외한다.** 포함하면 `충무로1가` 가 `충무 로1가` 로 파괴된다.
  도로명 주소는 애초에 `norm_road()`(기저 정규화만) 로 비교하므로 A 를 태우지 않는다.
- **B 는 lookahead 로 부번의 0 을 보호한다.** `617-01`·`617-0-2` 는 매치되지 않는다.
  리터럴 `-0` 이므로 `617-10` 도 애초에 매치 대상이 아니다.
- **C-1 은 lookbehind 로 지명의 `산` 을 막는다.** `중산동 1354`·`산황동 12` 는
  앞 글자가 한글이라 매치되지 않고, lookahead 가 `백석산길` 을 막는다.

### 3.1 최상위 불변식 — `산` 은 절대 지우지 않는다

    norm("…방동리 산282-1") != norm("…방동리 282-1")

산번지와 일반번지는 **서로 다른 필지**다. 통과율을 올리려고 `산` 을 무시하는 규칙을
만들면 채점기는 다른 땅을 같은 땅으로 세게 된다. 이 불변식은 기대값 595건 중
`산` 을 포함한 **161건 전수**에 대해 테스트로 고정돼 있다(위반 0건).

    python3 scripts/15-score-595.py invariant --xlsx <원본.xlsx>

## 4. 적용 순서와 보존 증명

정규화는 **합성 g∘f** 로 정의한다.

    norm_jibun = post_norm ∘ base_norm     # g ∘ f
    post_norm  = rule_b ∘ rule_a ∘ rule_c1 # 적용 순서 C-1 → A → B

`post_norm`(g) 은 `base_norm`(f) 의 **출력만** 입력으로 받고, g 안에서 f 를 다시
호출하지 않는다. 그러면 다음이 함수 정의상 따라온다.

    f(a) == f(b)  ⟹  g(f(a)) == g(f(b))

즉 **기존 하네스에서 통과하던 쌍은 규칙을 얹어도 절대 깨지지 않는다.** 이 보존은
데이터 측정이 아니라 합성 구조에서 나온다. 저장 덤프에는 불일치 행만 들어 있어
통과분 원문을 대조할 수 없는데, 이 성질 덕분에 측정 없이도 보존이 증명된다.
"g 가 f 를 재진입하지 않는다"는 전제는 `inspect.getsource` 검사로 테스트에 고정했다.

**순서를 C-1 부터 두는 이유**: 역지오 하네스의 기존 정규화는 이미
`f2 = rule_c1 ∘ f1` 이다. C-1 을 맨 앞에 두면 `g(f1(x)) = rB(rA(f2(x)))` 가 되어
f2 기준선의 통과분 보존도 같은 논증으로 성립한다. 순서를 A → B → C-1 로 바꿔도
595건 결과는 동일하지만 이 증명이 사라진다.

## 5. 정정표 — 규칙과 분리한다

`scripts/595-corrections.csv` (8열):

    no, expected_raw, expected_fixed, category, handler, applied_to_scoring, evidence_kind, evidence

두 축을 혼동하지 말 것.

- `handler` — 이 결함을 **무엇이** 처리하는가: `rule`(규칙 A/B/C-1) / `table`(정정표) / `deferred`(보류)
- `applied_to_scoring` — 이 행의 `expected_fixed` 를 **채점 치환에 실제로 쓰는가**: `1` / `0`

`handler=rule` 행은 전부 `applied_to_scoring=0` 이다. 규칙이 이미 대칭으로 처리하므로
치환이 불필요하며, 치환까지 하면 같은 보정을 두 번 하는 셈이 된다. 정정표의 rule 행은
**감사 기록**이지 채점 입력이 아니다.

정정표 치환은 **기대값에만** 적용하고 우리 출력에는 적용하지 않는다. 의도적 비대칭이며,
그래서 채점 적용 행은 최소로 유지한다 — 현재 **1건(NO334)** 뿐이다.

### 5.1 근거 종류(`evidence_kind`)

`grammar` · `db-absence-of-form` · `unique` · `string-defect` · `none` 다섯 값만 쓴다.

### 5.2 금지된 근거 — 자기참조

**xlsx 좌표를 근거로 기대 지번의 참·거짓을 판정하지 않는다.**

이 채점 자산의 좌표 594/595 는 **우리 순방향 지오코더의 출력**이다. 그 좌표로 PIP 를
쳐서 "기대 지번이 틀렸다"고 결론내면, 우리 출력으로 우리 출력을 검증하는 순환논증이 된다.
같은 이유로 "우리 parcel 에 그 필지가 없다"도 근거가 될 수 없다 — 우리 DB 의 결손과
자료의 오류를 구별하지 못한다.

`applied_to_scoring=1` 행에 좌표·PIP·거리·부존재 근거가 섞이지 않았는지는 테스트와
`corrections-stats` 가 검사한다. (보류 행의 "독립 좌표원 확보 후 재판단"이라는 서술은
채점에 쓰이지 않으므로 이 금지의 대상이 아니다.)

판정이 안 되면 **보류**한다. 모르는 값을 모른다고 남기는 것이 채점 자산의 신뢰도다.

## 6. 두 축과 각각의 기준선

절대 섞지 말 것. 둘 다 자기참조 지표이므로 대외 정확도 주장에 쓰지 않는다.

| 축 | 정의 | 기준선 |
|---|---|---|
| 왕복(roundtrip) | 기대 지번 → 우리 순방향 → 우리 역방향 | 516/595 = 86.7% |
| 역지오(reverse) | xlsx 좌표 → 우리 역방향 | 520/595 = 87.4% |

## 7. 사용법

    # 저장 덤프 재채점 (서버 호출 없음)
    python3 scripts/15-score-595.py rescore --axis roundtrip --dump DUMP.json --rules none
    python3 scripts/15-score-595.py rescore --axis roundtrip --dump DUMP.json --rules C-1,A,B
    python3 scripts/15-score-595.py rescore --axis roundtrip --dump DUMP.json \
            --rules C-1,A,B --corrections scripts/595-corrections.csv

    # 불변식 전수 검사 / 정정표 집계 / 자체 점검
    python3 scripts/15-score-595.py invariant --xlsx <원본.xlsx>
    python3 scripts/15-score-595.py corrections-stats --corrections scripts/595-corrections.csv
    python3 scripts/15-score-595.py --selftest
    python3 -m unittest scripts.test_addr_norm -v

서버 호출(`measure`)은 `--server` **필수**이며 기본값이 없다. 미지정이면 오류 종료한다.
운영 서버는 `--allow-production` 없이는 거부한다.
